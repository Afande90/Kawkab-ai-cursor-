# Entry surfaces of the `foss` release build, as the MERGED manifest declares them —
# what ships, after every library's own manifest has been folded in.
# `:app:verifyFossReleaseMergedManifest` (part of `check`) fails on any difference.
#
# Edited by hand, on purpose: every line is a decision. A new permission has to be
# explained in PRIVACY.md §5; an export without a permission has to be named in
# SECURITY.md § Automation triggers and entry surfaces. When the build fails, find
# where an added line comes from in app/build/outputs/logs/manifest-merger-*-report.txt.
# fullRelease.txt lists the same entries today; the flavours are checked separately
# because they ship separately — and only this one carries `absent` lines.
#
# Format — one entry per line, `#` starts a comment:
#   uses-permission NAME [maxSdkVersion=N]
#   permission NAME protectionLevel=LEVEL
#   exported TAG NAME permission=PERMISSION|none
#   queries package|intent|provider ...
#   absent TEXT        — no attribute of any element, exported or not, contains TEXT
