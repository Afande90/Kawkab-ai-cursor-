# M1 owner check

Date: 29 Oct 2026 (Asia/Dubai).

## What this milestone contains

- An outbound risk tier. A tap is required, and no approval setting turns it off.
- Phone actions for call, message, alarm, timer, and open, plus a calendar event. Every one goes through the denylist and, when it is outbound, a tap.
- A package denylist, screen heuristics, and an intent guard. Editing the package list needs a device confirmation.
- A private activity log. It can be exported as text. The app does not upload it.
- A frozen set of 200 typed commands, and a deterministic Arabic and English fast path for those shapes.
- A stub messenger (`testapps/stubmessenger`) with a compose screen, a Send button, and an inbox the instrumented test can query. WhatsApp itself is not on an emulator image.

## What to do on a phone

1. Install the foss arm64 release, turn on the Kawkab accessibility service, and allow restricted settings if Android asks.
2. Type "call" and a contact you have, then tap the confirmation card. The phone should open the call only after that tap.
3. Type a short message and confirm it. On a phone with WhatsApp this is the owner check for a real messenger. The emulator uses the stub messenger instead.
4. Open a banking or wallet app and confirm Kawkab does not tap there.
5. Set an alarm and a timer from a typed command and confirm each one.

This machine has no phone and no emulator, so those steps were not run here. The instrumented suite was not run. GitHub Actions was not observed from this machine.
