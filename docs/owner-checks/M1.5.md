# M1.5 owner check

Date: 30 Oct 2026 (Asia/Dubai).

## What this milestone contains

- The first chat is the Kawkab assistant. The screen says Kawkab. Knotwork stays on the About screen as the upstream credit.
- A typed line the grammar knows runs before any model load, and an outbound action still waits for a tap.
- Phone access, in English and Arabic, after setup finishes and from the privacy screen. Status lines for contacts, phone, calendar, notifications, microphone, the accessibility service, and battery. A missing grant shows a card that asks for it.
- Gemma 4 E4B is the default tool-call brain. Images stay on Gemma. A phone below 16 GiB of RAM still starts onboarding on Gemma 4 E2B. Qwen3 1.7B is selectable. The weights are not in the APK.
- The model stays on CPU, stays loaded between messages, and unloads after 2 idle minutes.

## What to do on a phone

1. Install the foss arm64 release from the Check artifact `kawkab-foss-arm64-release` on commit `ff0e9901`.
2. Finish setup. On Phone access, grant contacts, phone, calendar, notifications, and the microphone. Turn on the Kawkab accessibility service. If Android asks, allow restricted settings from the app info menu (the three-dot picture on that screen). Allow the battery exemption, and on Nothing OS set background use to unrestricted.
3. Confirm the first chat is Kawkab, and that "Knotwork" is not the chat name.
4. Type "call" and a contact, then tap the confirmation card. The call should open only after that tap. A line the grammar knows should not sit frozen while a model loads.
5. Type a sentence the grammar does not know. The phone should stay usable while the model answers, and the model should unload after it has been idle.
6. Make Kawkab the default assistant. A long-press of the power button, or the assistant gesture, should open the Kawkab panel over the current app. Approve and deny on that panel are the tap.
7. Repeat one command with the phone language set to Arabic.

This machine has no phone and no emulator. Those steps were not run here. GitHub Actions ran the instrumented suite on emulators for `ff0e9901` and it passed.
