1. Install the foss arm64 release APK.
2. Open the app once with the phone language set to English, and once set to Arabic.
3. In Arabic, confirm the layout runs right to left and the launcher name is كوكب.
4. Confirm the dark background is the deep-space ground and a confirmation uses the amber strip.
