# Reply-language set v1 (task 23g)

Twenty prompts, frozen before any tuning: 8 in Sudanese Arabic (`sd`), 6 in Modern Standard
Arabic (`msa`) and 6 in English (`en`). The reply to each must come once, in the prompt's own
language and dialect, with no language label and no translation.

`expect` is the language the reply must be in. Do not edit this file; add a v2 instead.
